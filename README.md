# 自動販売機シミュレーター (Vending Machine Simulator-Migration Version)
Webブラウザ上で動作する、自動販売機のシミュレーターの移行版（マイグレーション）アプリケーションです。

## プロジェクト概要
本プロジェクトは、以前開発したServlet/JSP版自動販売機シミュレーター（以下、旧版）のコアなロジックやドメインモデルを継承しつつ、よりモダンな技術スタックやアーキテクチャへの移行を目的としたマイグレーションアプリです。  

アプリの基本的なルールやシミュレーターとしての仕様（消費者ロール・業者ロールの2軸構成など）については旧版を踏襲しているため、本ドキュメントでは「移行における変更点」「技術的な刷新ポイント」を中心に記載します。

## 移行のポイント（旧版からの変更・進化点）
技術スタックのモダン化: Servlet/JSPからSpring Bootへ移行し、依存性注入（DI）やテンプレートエンジンの活用により保守性を向上  
アーキテクチャの再設計: 旧版のレイヤードアーキテクチャをベースにしつつ、責務の分離やコンポーネントの疎結合化をさらに推進。

## 使用技術 (Tech Stack)
言語: Java 21  
フレームワーク: Spring Boot  
ビュー: Thymeleaf  
データ管理: セッションスコープ  

## アーキテクチャ
旧版で構築した3層構造（Servlet / Service / DAO）の設計思想を受け継ぎつつ、フレームワークの機能（DIコンテナやORMなど）を活用したスマートな構成へ移行しています。
```text
[ ブラウザ ] 
   │ ▲ (HTTP Request / Response)
   ▼ │
┌────────────────────────────────────────┐
│ ■ View層 : Thymeleaf                  │  <- 画面表示、EL式によるデータ出力
└────────────────────────────────────────┘
   │ ▲
   ▼ │
┌────────────────────────────────────────┐
│ ■ Controller層 : Spring MVC Controller               │  <- リクエスト制御、セッション・遷移管理
└────────────────────────────────────────┘
   │ ▲
   ▼ │
┌────────────────────────────────────────┐
│ ■ Service層 : サービス・ドメインクラス │  <- ビジネスロジック（釣り銭計算、購入可否判定）
└────────────────────────────────────────┘
   │ ▲
   ▼ │
┌────────────────────────────────────────┐
│ ■ Repository層 : セッションなどによる管理     │  <- 自販機状態（在庫、売上、投入金額）の保持
└────────────────────────────────────────┘
```

## 起動方法
### 前提条件
Java 21 がインストールされていること
IDE（Spring対応のエディタ）
### 設定手順
プロジェクトのインポート  
Gradleプロジェクトとしてお使いのIDEにインポートしてください   
起動  
IDEからメインクラスを実行するかターミナルで以下のコマンドを実行してください
./gradlew bootRun
アクセス
ブラウザを開き、http://localhost:8080 にアクセスしてください。
